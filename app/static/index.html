Instructions

  • Ask Genie. Each challenge is a memo with five blanks. Ask in plain English, read the answer, type the value into the blank.
  • Ask as much as you like. Questions are free and unlimited, and a wrong answer costs you nothing — there is no penalty for how many you ask.
  • Be quick. A blank is worth 100 points and drops 5 every minute a challenge is open in front of you, never below 40.
  • The timer pauses. It only counts while you are actually on a challenge — switch screens, change tabs or close the laptop and it stops.
  • Hints cost 5 points. Each blank has one, it shows you the question to ask, and it is charged once no matter how often you open it.

    How this was made

    Four weeks of memos, a Genie space that reads the Bakehouse data, and one table that records what happened. No notebooks and no copy of the data.

    1. Bakehouse data Receipts, shops and customers, in Unity Catalog
    2. A Genie space Reads that data and answers plain English
    3. This app A Databricks App — the memo, the blanks, the clock
    4. One activity table Every question and answer, appended as it happens
    5. The leaderboard Read straight back out of that table

    No notebooks, no pipeline, no copy of the data: the game asks the same Genie space you would ask yourself, and writes what happened to one table.

      Operator access

      Entering it once keeps this browser unlocked for as long as the app stays running. A redeploy restarts the app, so everyone enters it again — that is expected.

      Operator

      On this page: release weeks · the activity log and its CSV · restore from an export · reset the game (deletes everyone's progress).

      Release weeks

      Tick a week to let every player unlock it. Nothing is scheduled — a week opens when you say so, and each player's own clock starts when they click to unlock.

      Client message

      An extra line on the home page, between the greeting and the welcome text — for example Welcome Acme team! Leave it empty and nothing is shown at all. It survives a redeploy, and it is the same for every player.

      Restore from a log export

      The export above is the backup. Loading one back merges it in by event id, so importing the same file twice changes nothing. Nothing is written until you press Import.

      Reset the game

      Deletes every score, answer, question, hint and clock — for everyone, not just you. The weeks you have released stay released, and the activity log's own record of the reset is kept. It cannot be undone, so a backup is taken and downloaded first.
